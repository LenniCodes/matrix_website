# Matrix Website

## Requirements
- Target: Mobile device users that want to enhance their sticker selection in Whatsapp or other platforms by self drawn gifs.
- Creation view where multiple frames can be hand drawn and combined to a gif
    - color selection
    - list of frames 
    - onion frames
    - add frame button
    - import frame from picture button
    - duration of frames
    - export button
- export option to export project file (and then being able to import it again)

## Optional
- Target: Owners of a matrix that runs on [PTSv2](https://gitlab.kit.edu/ubtvf/ptsv2).
    - Live transmission while drawing
    - Send to matrix instead of export as gif
    - IP field to set/change the esps address

- Overview page of created animations and storing in database (e.g. Firebase)
- Isometric transformations within a certain amount of frames
